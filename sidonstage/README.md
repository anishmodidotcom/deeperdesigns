# Sid on Stage

Standalone static site for Siddhant Pamnani. Lives in this folder, isolated from the main Deeper Designs app. Built with Next.js 16 (static export) and served by the existing DD Vercel deploy at `deeperdesigns.in/sidonstage`.

## What lives here

```
sidonstage/
  app/                Next.js App Router pages and layout
  components/         All UI sections
  lib/                Hooks and helpers
  scripts/
    generate-images.ts    Nano Banana atmospheric stills
    extract-pdf-assets.ts Pulls images from siddhant-profile.pdf
    image-manifest.json   Atmos prompts
    cost-log.json         Generation spend log
  reference/          Drop siddhant-profile.pdf here (gitignored)
  raw-extracted/      pdfimages dump (gitignored)
  public/
    assets/atmos/     Generated atmospheric stills
    assets/extracted/ Photos sorted into category folders
    videos/hero/      hero-loop.mp4 + hero-poster.webp (drop in once Omni Flash render is done)
```

## Local development

```bash
cd sidonstage
bun install               # uses package.json in this folder, NOT the DD app's
bun run dev               # http://localhost:3000/sidonstage
```

## Adding the hero video

The Omni Flash developer API is not yet available, so the hero video is generated by hand in the Gemini app or Google Flow (image to video on Siddhant's best stage photo).

Prompt to use:

> Cinematic slow push in on a confident male corporate emcee holding a microphone on a dark stage. Subtle living motion: he breathes and shifts slightly, stage haze drifts, soft blue spotlights shimmer and sweep behind him, a blurred audience moves faintly in the background. Premium, high end, moody blue and black color grade, shallow depth of field, no text, seamless loopable, 8 to 10 seconds.

Drop the result into:

```
public/videos/hero/hero-loop.mp4
public/videos/hero/hero-poster.webp
```

The hero detects them at build time. If they are missing it falls back to a Ken Burns slow zoom on the hero portrait plus the animated haze and light beams layers, so the site always looks finished.

## Swapping placeholder photos for high res originals

Image filenames are the contract. Replace any file in `public/assets/extracted/<category>/` with a higher resolution version of the same filename and rebuild. No code change required.

Categories:

```
public/assets/extracted/
  hero/           main.webp           Hero portrait (used if no video)
  portraits/      01.webp ...         About section portrait fallback
  corporate/      *.webp              Corporate Presenter rail
  teambuilding/   *.webp              Team Building rail
  sports/         *.webp              Sports Presenter rail
  logos/          *.webp or *.svg     Trusted by brand wall
  testimonials/   *.webp              Reserved for testimonial avatars
```

## Generating atmospheric stills

```bash
cp .env.local.example .env.local
# fill GEMINI_API_KEY
bun run gen:atmos
```

Skips files that already exist. Total stay under 14 generations, under 0.50 USD. Spend is tracked in `scripts/cost-log.json`.

## Extracting from the profile PDF

Drop `siddhant-profile.pdf` into `reference/`, then:

```bash
bun run extract:pdf
```

This uses `pdfimages` (preferred) or `python3 + PyMuPDF` (fallback) to dump all embedded rasters into `raw-extracted/`, upscales 2x with sharp lanczos3, and writes WebP to `public/assets/extracted/_staging/`.

After the dump completes, visually sort the staged WebPs into the category folders above. Then update `ASSETS.md` with the slot map.

## Building and exporting

```bash
bun run export:public
```

This runs `next build` (static export, `output: 'export'`) and copies the contents of `out/` to `../public/sidonstage/`. The DD Vercel deploy serves those files at `deeperdesigns.in/sidonstage`.

The `out/` folder is gitignored. `../public/sidonstage/` is NOT, because Vercel needs those committed files.

## Web3Forms contact form

Optional. To enable:

```
NEXT_PUBLIC_W3F_KEY=your-key   # in .env.local
```

If no key is set, the form is hidden and only WhatsApp plus socials appear.
