# Brand logos

Third-party tool marks for use in Deeper Designs and Anish Modi design systems.
Copied from `logo-pack-v2.zip` (39 marks). Nothing here is referenced from the
site yet.

## Rules, from the pack

- Third-party marks are monochrome and uniform in size on any surface.
- Only the Claude mark may appear in colour, at `#D97757`. That file is
  `claude-coral.svg`.
- `anthropic.svg` is the corporate A glyph, not the Claude mark.
- Use is nominative. The marks remain their owners' trademarks.

## Source

Every file below comes from `logo-pack-v2.zip`, which sources its marks from
cdn.simpleicons.org (CC0 icon set). The pack ships each mark in three variants:
`brand/` (official colour), `white/` (for dark surfaces) and `black/` (for
light surfaces, recolour to ink). This folder carries the `black/` variant,
which is the monochrome baseline: a single `fill="#000000"` that is trivial to
recolour to any ink. The one exception is `claude-coral.svg`, taken from
`brand/claude.svg` so the coral is preserved.

official brand centres, never from image sites: LinkedIn
(brand.linkedin.com), Microsoft and Excel (Microsoft brand centre), Slack
(slack.com/media-kit), Canva (canva.com/brand), OpenAI and ChatGPT
(openai.com/brand).
